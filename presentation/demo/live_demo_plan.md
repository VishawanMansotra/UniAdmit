# Live Demo Plan (12 Minutes)

## Demo objective
Show complete value chain: student flow + admin governance + chatbot assistance.

## Click path and timing
1. **00:00–01:00** Home overview and value proposition
2. **01:00–03:00** Student login/dashboard and profile context
3. **03:00–05:30** Application flow (`/apply/`) and key fields/documents
4. **05:30–07:00** Payment flow explanation (initiate + verify checkpoints)
5. **07:00–09:00** Admin dashboard + admission-round control + merit publication
6. **09:00–10:30** Chatbot query, response, and feedback submission
7. **10:30–12:00** Summarize outcomes and transition to Q&A

## Fallback strategy
- If internet/API fails: use pre-captured screenshots in sequence
- If payment callback fails: explain verification step using flow diagram
- If AI rate limit/error: show unresolved query and feedback mechanism

## Expected outputs to show
- Application creation and status visibility
- Admin-level control of rounds/results
- Chatbot response and quality-improvement loop evidence
