# Screenshot Capture Checklist

Save all captures under: `presentation/assets/screenshots/`

## Required screens
1. Home page (`/`)
2. Student dashboard (`/dashboard/`)
3. Apply page (`/apply/`)
4. Admin dashboard (`/admin-dashboard/`)
5. Chat widget/panel (home/base with chatbot component)

## Capture standards
- Resolution: 1920x1080
- Browser zoom: 100%
- Use same browser/theme for all screenshots
- Remove personal email/phone data before final deck
- Prefer cards/flows visible above the fold

## Suggested naming
- `01-home.png`
- `02-student-dashboard.png`
- `03-apply.png`
- `04-admin-dashboard.png`
- `05-chatbot-panel.png`
